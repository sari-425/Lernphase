# THE FINAL GAME – Konzepttrailer

**100 PLAYERS. ONE GAME. YOUR DECISION.**

Ein 60-Sekunden-Konzepttrailer (16:9, 1920 × 1080, 24 fps, Stereo 48 kHz, −14 LUFS) für eine interaktive Social-Media-Spielshow, in der die Follower selbst die Spieler sind.

- Fertiger Film: `THE_FINAL_GAME_Trailer_1080p.mp4`
- Quellen: `scene.html` (3D-Szenen und Schrift), `render.mjs` (Bild-für-Bild-Renderer), `audio.py` (Score und Sounddesign)

Alles in diesem Trailer ist eigens für das Projekt entstanden: Geometrie, Licht, Typografie, Musik und Effekte werden aus Code erzeugt. Es gibt kein Stockmaterial, keine Fremdmusik und keine Wasserzeichen.

### Dramaturgische Änderungen gegenüber der Vorlage
- **Szene 4 endet mit einer Konsequenz**: Die Abstimmung öffnet tatsächlich Tür B. Das zeigt, dass die Zuschauer das Spiel steuern und nicht nur zusehen.
- **Szene 5:** Die Kennung des letzten Spielers wird zu **SPIELER: DU**. Das ist die Pointe auf „Und du?“.
- **Call-to-Action im Logo:** „Kommentiere. Entscheide. Spiele mit.“
- Jede Herausforderung trägt eine Rundennummer. Das macht das Format als Serie lesbar.
- Es gibt keine Verletzungen und keine tödliche Gefahr. Die Spannung entsteht aus Entscheidung, Zeit und Vertrauen.

## 3. Musik und Sounddesign
Eine eigene Komposition in d-Moll mit eigener Akkordfolge (Dm → B♭ → Gm/D → A → Dm). Sie besteht aus synthetischen Streicherflächen, einem Sub-Drone, einem Herzschlag-Puls (66 → 98 → 104 BPM, im Finale ausdünnend), Braams auf den großen Schnitten, Risern, Foley für Tor, Countdown und Kommentare sowie einem 4-Ton-Signaturmotiv (D – A – F – E) zum Logo. Vor „Und du?“ wird die Musik fast stumm geschaltet (Ducking), danach setzt der Markenhit ein.

**Sprecher:** ElevenLabs-Stimme **„Haunting-Hector – Dark Cinematic“** (Modell Eleven v3, ein durchgehender Take für alle neun Sätze, unbearbeitet). Sie wird nur geschnitten, auf die Einsatzpunkte der Tabelle gelegt und duckt die Musik automatisch. Die frühere synthetische Stimme (espeak-ng/MBROLA, `build_audio.sh`) dient nur noch als Ausweichlösung.

Einsatzpunkte: 1,15 s · 7,7 s · 9,65 s · 12,35 s · 14,4 s · 37,0 s · 45,6 s · 49,6 s · 53,95 s.

## 4. Qualitätskontrolle

| Frage | Bewertung |
|---|---|
| Wirkt es wie ein Filmtrailer? | Ja, im Rahmen der Machart: Kinolicht, Bloom, Nebel, Vignette, Kamerafahrten und Ton-Dramaturgie mit Hits auf den Schnitten. Fotorealistische Menschen liefert dieser Renderer nicht. Die Figuren sind bewusst stilisierte Silhouetten. |
| Interesse in den ersten 5 Sekunden? | Schwarz, dann eine Stimme, die den Zuschauer direkt anspricht, und die aufzählende 100 mit dem roten Schnitt |
| Ist die Spielidee verständlich? | 100 Spieler, nummerierte Runden mit Rätseln, Entscheidungen und Vertrauen, dazu eine Rangliste |
| Nehmen echte Zuschauer teil? | Kommentare auf dem Smartphone, kippende Abstimmung, Tür B öffnet sich, „SPIELER: DU“ |
| Ist die Identität eigenständig? | Eigene Symbole (roter Schnitt, Lichtschlitz der Kuratoren, Halle der 100). Keine fremden Masken, Formen, Kostüme oder Musik |
| Bleibt der Markenname hängen? | Er erscheint auf dem Smartphone und im Logo mit Markenhit. Die Schreibweise **THE FINAL GAME** ist überall geprüft |
| Will man mehr sehen? | Offene Fragen (Was ist hinter Tür B? Wer sind die Kuratoren?) und ein direkter Aufruf zum Mitspielen |

## 5. Neu rendern

```bash
cd trailer/the-final-game
npm i three@0.160.0                 # einmalig
apt-get install espeak-ng mbrola mbrola-de2 mbrola-de6   # Sprecher
pip install numpy scipy
node render.mjs video_raw.mp4 0 60 24      # Bild (Playwright/Chromium)
python3 audio.py                            # Score -> score.wav
# Sprecher erzeugen und mischen: siehe build_audio.sh
```
